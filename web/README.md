# Alertamiento S&iacute;smico TAKAB

Panel web para monitoreo sismico, estado de estaciones y visualizacion de datos operativos de la red Raspberry Shake 4D (RS4D).

## Stack actual

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Requisitos

- Node.js 20+
- npm 10+

## Desarrollo local

```bash
npm install
npm run dev
```

## Build y pruebas

```bash
npm run lint
npm run test
npm run build
```
